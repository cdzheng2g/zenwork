# 图像算子公共能力更新（2026-10-19）

## 已完成

- 新建独立 `hans_inference` 构建目标，RKNN SDK 调用集中到 `RknnSession`，公开接口不暴露 SDK 类型。
- 支持查询全部输入/输出、提交多个输入、复制多个 float32 输出；RAII 释放输出和模型，失败的替换保留旧会话。
- 提取原图/校正图选择、ROI 校验与裁剪，统一 ROI 到原图的坐标映射。
- 提供 Stretch / Letterbox 和逆变换，以及置信度过滤、同类别 NMS、检测框序列化。
- 参数框架增加 File 类型；图像算子可通过 `advanced` 明确声明折叠参数。
- 新增通用图像编辑器：ROI、资源文件选择和普通参数表单自动组合。
- OCR 改用公共能力，删除 `OcrOperatorPanel.h/.cpp`，保留模型专属文字检测和识别处理。
- 预览支持单个 region，也支持通用检测类别标签；不再只在多个文字区域时绘制 region。
- 保留用户已添加的 brightness 算子及其注册和编译项。

新增检测算子的教程：[adding-detection.md](adding-detection.md)。
四个示例文件在 `docs/examples/detection`；没有向应用注册尚未完成解析的检测算子。

## 验证

- RK3576 主程序、全部现有测试目标和 `detection_example` 编译通过。
- 板子临时目录中运行 14 项自动检查，全部通过；UI 组件测试采用 offscreen，无应用窗口交互。
- `test_rknn_session` 使用替代 SDK，验证多输入/三输出、缓存复用、失败回退和缓冲区释放；不是实际检测模型的正确性验证。
- 板子真实 RKNN OCR 对比：使用同一张合成 `ABC123` 图像，分别执行修改前与修改后的引擎。区域、倒置尝试、整图三种模式的完整结果对象完全一致。
- 三种模式均识别出 `ABC123`；区域/倒置模式置信度为 0.83146159，整图为 0.82999674。
- 逐项日志在 `checks/shared-operators-20261019-155113/`。

本次验证没有替换或重启板子上的正式应用。触屏或 MobaXterm 的实际界面验收由用户进行。
检测示例仍需根据真实模型实现 `decode()`，并确认 RGB、归一化、补边等前处理约定。
